# Уставы

Собирает оглавление библиотеки образцов — `1-Работа/Регистрация/Образцы уставов/ИНДЕКС.md`.

## Запуск

```
python3 2-Автоматизации/ustavy/indeks.py
```

Проходит по всем паспортам образцов и строит таблицы: сколько чего есть, и по каждой форме — направление, название, территория, год, членство, доходная деятельность.

Запускать после каждого добавления образца.

## Массовая загрузка

Разовая заливка выгрузки с сайта Минюста — по инструкции [ПРОМТ-загрузка-уставов.md](ПРОМТ-загрузка-уставов.md), отдельной сессией.

Главное правило оттуда: **исходные PDF в хранилище не попадают**. Выгрузка на 300 уставов весит 1,7 ГБ — люди не смогут её скачивать. В хранилище идут текст и паспорт, на оригинал ставится ссылка.

## Что сломается, если убрать

Образцы останутся, но искать их придётся перебором папок. При двух сотнях уставов это означает, что искать перестанут вовсе.
