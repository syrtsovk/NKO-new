# Промт для загрузки библиотеки уставов

Отдельная сессия, разовая операция. Скопировать всё, что ниже разделителя, и отправить в новую сессию Claude Code, запущенную **в папке этого репозитория**.

---

## Задача

Ты загружаешь библиотеку образцов уставов НКО в общий репозиторий центра НКО Санкт-Петербурга.

Библиотека нужна, чтобы помогать новым организациям писать уставы: устав, который уже прошёл регистрацию в Минюсте, — надёжный источник формулировок, в отличие от шаблонов из интернета. Помощник будет подбирать образец по форме организации и направлению деятельности, поэтому главное в твоей работе — **не перенести файлы, а разложить их так, чтобы потом находились нужные**.

## Что на входе

`~/Downloads/minjust-ustavy/` — выгрузка с сайта Минюста:

- **300 PDF**, разложены по четырём формам: `АНО`, `Фонды`, `Общественные организации`, `Ассоциации и союзы`, по 75 в каждой;
- **`реестр-уставов.csv`** — метаданные на все 300: форма, название, ОГРН, дата ОГРН, учётный номер, регион, адрес, статус, имя файла, ссылка на оригинал.

Два факта, которые уже проверены — перепроверять не нужно, но учитывай:

1. **Папка весит 1,7 ГБ. Исходные PDF в репозиторий не переносятся ни в каком виде.** В репозиторий идут только текст устава и паспорт; на оригинал ставится ссылка из CSV.
2. **190 файлов из 300 (63%) — сканы без текстового слоя.** Утилита `pdftotext` возвращает по ним пустоту. Работаешь только со 110 читаемыми; сканы — отдельная задача, см. конец.

## Что на выходе

В `1-Работа/Регистрация/Образцы уставов/` на каждый обработанный устав:

```
<Форма>/<ОГРН>-<короткое-имя-латиницей>/
├── паспорт.md   ← метаданные и разбор
└── текст.md     ← полный текст устава
```

**Прочитай перед началом** — это твои спецификации:

- `1-Работа/Регистрация/Образцы уставов/README.md` — как устроена библиотека и что за поля в паспорте;
- `1-Работа/Регистрация/Образцы уставов/_рубрикатор.md` — закрытый список направлений;
- `1-Работа/Регистрация/Образцы уставов/АНО/1252500018781-pravo-na-pravdu/` — **готовый эталонный образец**. Делай точно так же: тот же набор полей, та же глубина разбора, тот же тон.
- `AGENTS.md` и `МЕТОДОЛОГИЯ.md` в корне — общие правила репозитория.

## Порядок работы

### Шаг 1. Подготовить тексты

Извлеки текст из всех PDF во временную папку — так агенты не будут гонять `pdftotext` по очереди:

```
mkdir -p /tmp/ustavy-text
cd ~/Downloads/minjust-ustavy
find . -name "*.pdf" | while read f; do
  out="/tmp/ustavy-text/$(basename "${f%.pdf}").txt"
  pdftotext -layout "$f" "$out" 2>/dev/null
done
```

Отбери те, где больше 1000 символов, — это и есть читаемые. Их должно получиться около 110. Получилось сильно меньше — остановись и скажи об этом, не выдумывай обходные пути.

### Шаг 2. Разложить работу по агентам

Собери список читаемых уставов и раздай его подагентам **партиями по 10–12 штук**. Каждый агент делает свою партию целиком: читает текст, заполняет паспорт, кладёт текст. Работай в несколько агентов параллельно, но не больше пяти одновременно.

Каждому агенту в задании дай: список его файлов, путь к эталонному образцу, путь к рубрикатору и требования из шага 3.

### Шаг 3. Что делает агент с одним уставом

1. **Метаданные берёт из CSV, а не из текста.** ОГРН, название, регион, дата регистрации, ссылка на оригинал уже есть в `реестр-уставов.csv`. Вытаскивать их из текста заново — лишняя работа и лишние ошибки.

2. **Направление определяет по разделу целей и предмета деятельности** — и берёт **только код из рубрикатора**. Своих формулировок не изобретает. Ничего не подходит — ставит `prochee` и пишет в паспорте, чем организация занимается. Пограничный случай (например, правовое просвещение — это `pravo` или `obrazovanie`) решается по основной, а не по побочной цели.

3. **Признаки вытаскивает из текста:**

   | Поле | Где искать |
   |---|---|
   | `членство` | «члены Организации», «приём в члены» — есть у общественных организаций и ассоциаций, нет у АНО и фондов |
   | `доходная_деятельность` | «приносящая доход деятельность», «предпринимательская деятельность» |
   | `попечительский_совет` | «попечительский совет» — у фондов обязателен |
   | `филиалы` | «филиалы и представительства» — только если реально созданы, а не упомянуты как возможность |
   | `территория` | Обычно прямо в названии: местная, региональная, межрегиональная, общероссийская |

4. **Пишет разбор** — по эталону, три коротких раздела: чем полезен, что стоит переиспользовать, особенности. Разбор должен быть **конкретным**: не «хороший устав с чёткими целями», а «предмет одной строкой, цели списком из четырёх пунктов, виды деятельности отдельным пунктом со связкой „в соответствии с целями“». Общие похвалы бесполезны — их нельзя применить.

5. **Кладёт текст** в `текст.md` с заголовком и ссылкой на оригинал сверху.

6. **Затирает ФИО учредителей**, если они попали в текст — заменяет на `[ФИО учредителя]`. Названия организаций, юридические адреса и ОГРН остаются.

### Шаг 4. Собрать индекс и проверить

```
python3 2-Автоматизации/ustavy/indeks.py
```

Затем проверь глазами:

- в индексе столько образцов, сколько обработано;
- в каждой форме есть образцы, направления распределены осмысленно;
- нет направлений вне рубрикатора — это главная ошибка, которая ломает поиск;
- пустых паспортов и обрезанных текстов нет;
- PDF в репозиторий не попали: `git status` не должен показывать ни одного `.pdf`.

### Шаг 5. Сохранить

```
git add -A
git commit -m "Библиотека уставов: <сколько> образцов из выгрузки Минюста"
git push
```

## Что важнее всего

**Разбор ценнее текста.** Текст можно скачать у Минюста в любой момент — ссылка есть в паспорте. Смысл этой работы в том, что человек за пять минут находит подходящий образец вместо трёх часов чтения. Если разборы окажутся пустыми и одинаковыми, вся затея бессмысленна.

**Единообразие направлений важнее их точности.** Ошибка в рубрике заметна и правится. Три разных названия одной рубрики не заметит никто, и часть библиотеки станет ненаходимой.

## Чего делать нельзя

- Копировать PDF в репозиторий. Никакие, ни в каком виде, даже «для нескольких важных».
- Придумывать направления вне рубрикатора.
- Заполнять поля наугад, когда в тексте признака нет. Не нашёл — оставь пустым и напиши в паспорте, что не определено.
- Пересказывать устав в разборе. Разбор — про то, что переиспользовать, а не про содержание.
- Трогать что-либо вне папки `Образцы уставов` и файла индекса.
