# Здоровье

Проверяет реестр на то, что портится незаметно, и складывает отчёт в `1-Работа/ЗДОРОВЬЕ.md`.

## Запуск

```
python3 2-Автоматизации/zdorovie/zdorovie.py
```

| Ключ | Что делает |
|---|---|
| `--telegram` | Отправит итог в телеграм |
| `--tihiy` | Промолчит, если всё чисто. Для еженедельного расписания |
| `--data 2026-09-01` | Посчитает на другую дату |

## Что проверяется

**Про данные:**

| Проверка | Почему это важно |
|---|---|
| Сломанные даты | Дата не вида `2026-08-24` — срок по ней не считается вообще |
| Чужие поля | Опечатка в названии поля. Поле не читается ничем, срок теряется |
| Непонятные значения | Значение вне списка допустимых — отчёты начинают врать |
| Сканы без карточки | Файл лежит, карточки нет — для поиска письма не существует |
| Организации задвоились | Похожие названия. Переписка расходится на две ленты |
| Дела разъехались | Одно дело названо по-разному. Цепочка рвётся |
| Письма без дела и без сроков | Выпадают из истории спора и из контроля сроков |
| Забыли закрыть, висят больше года | Мусор в открытых, из-за него не видно настоящего |
| Карточки не заполнены | Непонятно, кто ведёт организацию |

**Про саму систему:**

| Проверка | Почему это важно |
|---|---|
| Сводку не пересобирали больше недели | Просрочки сейчас никто не видит |
| Работу не сохраняли больше двух недель | Либо не работают, либо перестали отправлять в общее место — второе хуже |

Вторая часть — самая важная. Скрипты и привычки ломаются молча: расписание упало, телеграм не шлёт, человек забыл говорить «сохрани». Заметить это можно только по датам.

## Как поймать похожесть

Названия сравниваются двумя способами: по проценту совпадения и по вхождению одного в другое. Второе ловит самый частый вид разъезда — когда к названию добавили слово: «Ставка по Садовой» и «Льготная ставка по Садовой» по проценту не совпадают, а это одно дело.

Ловится и подмена букв: «Ромашка» с латинской `a` глазом не отличается от русской.

## Еженедельная отправка

```
0 10 * * 1 cd /путь/к/папке && /usr/bin/python3 2-Автоматизации/zdorovie/zdorovie.py --telegram --tihiy >> /tmp/zdorovie.log 2>&1
```

Понедельник, 10 утра, молча, если всё чисто.

## Что сломается, если убрать

Ничего сразу. Через полгода — половина реестра перестанет находиться, и никто не поймёт, когда это началось. Это и есть главная опасность: поломка без момента поломки.
