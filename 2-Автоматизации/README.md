# Автоматизации

Программы, которые делают рутину сами. Настраивает и меняет их администратор — остальным сюда заходить не нужно.

| Что | Папка | Зачем |
|---|---|---|
| Сроки | [sroki](sroki/) | Считает просрочки по переписке, пересобирает `1-Работа/СВОДКА.md`, шлёт напоминание в телеграм |

## Что нужно для запуска

Только Python 3.9 или новее — он уже есть на Маке и на большинстве машин. Сторонних библиотек нет намеренно: чем меньше движущихся частей, тем меньше поводов для поломки.

Проверить:

```
python3 --version
```

## Куда класть новые автоматизации

Отдельная папка на каждую, внутри — `README.md` с ответами на три вопроса: что делает, как запустить, что сломается, если убрать.
