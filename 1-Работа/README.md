# Документы и файлы для работы

| Папка | Что внутри |
|---|---|
| **Организации** | По папке на каждую НКО: реквизиты, помещения, вся переписка |
| **Регистрация** | Помощь новым организациям: пакеты документов и образцы уставов |
| **Шаблоны** | Заготовки писем и документов |
| **СВОДКА.md** | Что горит по срокам. Собирается сама, руками не править |
| **Организации/ИНДЕКС.md** | Все организации с счётчиками. Отсюда начинается любой поиск |
| **&lt;организация&gt;/ЛЕНТА.md** | Вся переписка организации по делам, свежее сверху |

## Как заводится новая организация

Скажи помощнику: «заведи организацию АНО „Ромашка“». Он сделает папку по шаблону и спросит недостающие реквизиты.

## Как заводится письмо

Скажи «пришло письмо» и дай текст, скан или фотографию. Помощник вытащит суть, найдёт сроки и заведёт карточку в нужную организацию. Если срок в письме не указан — посчитает 30 дней от даты получения и честно пометит, что срок расчётный.

## Почему поиск работает быстро

Писем со временем станут тысячи. Чтобы помощник не перебирал их подряд, есть два оглавления — общий индекс организаций и лента по каждой. Он идёт сверху вниз: индекс → лента → нужное письмо. Оба файла собираются сами при каждом заведении письма.

Письма связаны в **дела** — например «Льготная ставка по Садовой». Одно письмо без своего дела читается неправильно: претензия выглядит справедливой, пока не видно, что мы трижды просили перерасчёт и нам не ответили.
