# Регистрация новых НКО

Здесь готовятся учредительные документы для организаций, которые только создаются.

| Папка | Что внутри |
|---|---|
| **Заявки** | По папке на каждую организацию: черновик устава, чеклист подачи, переписка с Минюстом |
| **Образцы уставов** | Уставы, которые уже прошли регистрацию |

## Как начать

Скажи помощнику: «регистрируем новую организацию». Он задаст вопросы — как называется, чем будет заниматься, кто учредители — и соберёт черновик устава под эти виды деятельности.

## Про образцы

**Папка с образцами — самое ценное, что здесь может лежать.** Устав, который уже прошёл Минюст, показывает формулировки, которые реально принимают. Это надёжнее любых типовых шаблонов из интернета.

Прошла регистрация — положи устав сюда и подпиши в начале файла, когда и в каком регионе он прошёл.

## Важное про черновики

Помощник делает **черновик**, а не документ для подачи. Минюст отказывает по мелким придиркам к формулировкам, а отказ — это повторная пошлина и потерянный месяц. Перед подачей документы смотрит юрист.
