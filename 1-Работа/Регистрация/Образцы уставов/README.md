# Образцы уставов

Библиотека уставов, **прошедших регистрацию в Минюсте**. Это самый ценный материал для помощи новым организациям: такой устав доказал, что его формулировки принимают. Любой шаблон из интернета слабее.

## Как устроено

```
Образцы уставов/
├── ИНДЕКС.md          ← таблица всех образцов, отсюда начинается поиск
├── _рубрикатор.md     ← закрытый список направлений
├── АНО/
│   └── 1233100002926-tsentr-sodeystviya/
│       ├── паспорт.md   ← метаданные и разбор, читается первым
│       └── текст.md     ← полный текст устава
├── Фонды/
├── Общественные организации/
└── Ассоциации и союзы/
```

**Порядок поиска — как везде здесь:** `ИНДЕКС.md` → паспорт подходящего образца → текст, если он действительно нужен. Тексты большие, читать их подряд нельзя.

## По каким признакам ищем

| Признак | Зачем |
|---|---|
| **Форма** | АНО, фонд, общественная организация, ассоциация. Задаёт весь скелет устава |
| **Направление** | Спорт, дети, экология и так далее — из рубрикатора. Главная ось: формулировки целей у похожих организаций похожи |
| **Территория** | Местная, региональная, межрегиональная, общероссийская |
| **Год регистрации** | Свежие образцы надёжнее: требования меняются. Устав 2012 года — справочно, не для копирования |
| **Особенности** | Есть ли членство, приносящая доход деятельность, филиалы, попечительский совет |

## Как добавить новый образец

1. **Проверь, что он прошёл регистрацию.** Непрошедшие уставы здесь не нужны — они учат неправильному.
2. Определи форму и заведи папку `<Форма>/<ОГРН>-<короткое-имя-латиницей>/`.
3. Положи `текст.md` — полный текст устава.
4. Заполни `паспорт.md` по образцу ниже. Направление берётся **только из рубрикатора**.
5. Пересобери индекс: `python3 2-Автоматизации/ustavy/indeks.py`
6. Скажи «сохрани».

Проще всего — попросить помощника: «добавь образец устава», дать файл и ответить на пару вопросов.

## Массовая загрузка

Разовая заливка большой выгрузки с сайта Минюста делается отдельной сессией по готовой инструкции — `2-Автоматизации/ustavy/ПРОМТ-загрузка-уставов.md`. Там же описано, почему исходные PDF в хранилище не попадают.

## Паспорт образца

```yaml
---
огрн: 1233100002926
название: Автономная некоммерческая организация «Центр содействия...»
форма: АНО                      # АНО | Фонд | Общественная организация | Ассоциация или союз
направление: obrazovanie        # только код из _рубрикатора.md
территория: regionalnaya
регион: Белгородская область
зарегистрирован: 2023-04-12
членство: нет                   # да | нет
доходная_деятельность: да       # ведёт ли деятельность, приносящую доход
попечительский_совет: нет
филиалы: нет
источник: https://nco.minjust.gov.ru/...
качество_текста: распознан      # текстовый слой | распознан | нет текста
---
```

Дальше в паспорте — короткий разбор: чем этот устав полезен, какие формулировки целей и предмета деятельности стоит переиспользовать, что в нём необычного.

## Чего здесь быть не должно

- Уставов, не прошедших регистрацию.
- Исходных PDF: они весят сотни мегабайт и людям пришлось бы качать их все. В паспорте есть ссылка на оригинал у Минюста — этого достаточно.
- Персональных данных учредителей, если они попали в текст: имена в разделе об учредителях затираются при добавлении.
