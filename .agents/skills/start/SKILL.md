# Начать сессию

Человек сел работать. Твоя задача — привести его копию в актуальное состояние, ничего при этом не потеряв, и сказать, за что браться.

Никогда не показывай ему команды и не проси ничего вводить. Делай сам, отчитывайся по-человечески.

## Шаг 1. Проверить, кто он

```
git config user.name
```

Пусто — спроси имя и фамилию, запиши через `git config user.name` и `git config user.email`. Без этого непонятно, кто что сделал, и аварийное восстановление работает вслепую.

Заодно проверь, есть ли в корне папка `_личное`. Нет — создай молча, без комментариев. В общее хранилище она не уходит, но она нужна: туда кладут то, что нельзя показывать остальным.

## Шаг 2. Спасти незакрытое с прошлого раза

```
git status --porcelain
```

Пусто — иди дальше. Есть строки — значит, с прошлого раза остались несохранённые правки. **Это самое опасное место всей работы: именно здесь теряют данные.**

1. Скажи человеку простыми словами, что у него осталось незакрытым, и перечисли по смыслу: «два письма по Ромашке и черновик устава для Надежды».
2. Проверь эти файлы на запрещённое (`0-Начало/4-что-нельзя-класть.md`). Нашёл паспорт, справку, ключи — останови и разберись с этим сначала.
3. Зафиксируй их прямо сейчас, до всякого обновления:
   ```
   git add -A
   git commit -m "Незакрытое с прошлого раза"
   ```
   Коммит надёжнее, чем прятать во временное хранилище: его видно и он не пропадёт.

## Шаг 3. Посмотреть, насколько отстали

```
git fetch
git log --oneline HEAD..@{u}
```

Строк много — человек давно не заходил. Скажи об этом прямо: «Тебя не было три недели, за это время коллеги сделали 47 изменений». Дальше действуй осторожнее и подробнее объясняй.

## Шаг 4. Обновиться

```
git pull --rebase
```

Прошло гладко — отлично. Ругнулось на конфликт — переходи к разделу «Если разошлось».

## Шаг 5. Пересобрать сводку

```
python3 2-Автоматизации/sroki/sroki.py
```

## Шаг 6. Рассказать, за что браться

Три абзаца, без путей к файлам и без слова «коммит»:

1. **Что изменилось, пока его не было** — по смыслу, а не списком: «Петров завёл претензию по Ромашке и ответил комитету по Надежде».
2. **Что горит** — из сводки, самое срочное первым.
3. **Что осталось от него самого** — если на шаге 2 что-то спасали, напомни, что это никуда не делось.

## Если разошлось

Значит, вы с коллегой правили одно место.

1. **Никогда не выбирай сам, чей текст оставить.** Это решение человека, а не твоё.
2. Покажи оба варианта обычным текстом: «У тебя написано так, у коллеги — так».
3. По его выбору доведи до конца: `git add <файл>`, затем `git rebase --continue`.
4. Человек не понимает, что происходит, или вариантов много — не мучай его. Откатись в безопасное состояние (`git rebase --abort`), скажи, что ничего не потеряно, и позови администратора.

## Чего не делать

- Не делать `git reset --hard`, пока есть несохранённые правки. Это единственная команда, которая по-настоящему уничтожает работу.
- Не делать `git checkout --ours` или `--theirs` без явного выбора человека — это молча выкидывает чью-то работу.
- Не пропускать шаг 2, даже если человек торопится. Обновление поверх несохранённого — главный способ потерять чужой день.
