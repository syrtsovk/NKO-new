# Откуда взяты заготовки

Часть заготовок написана под этот репозиторий, часть перенесена из других проектов. Файл нужен, чтобы перенесённые не разъехались с оригиналами: правка в одном месте не долетает до другого автоматически.

| Заготовка | Происхождение | Версия на момент переноса |
|---|---|---|
| `start`, `finish` | Написаны здесь | — |
| `pismo`, `sroki`, `naiti`, `otvet`, `ustav` | Написаны здесь | — |
| `humanvoice` | Перенесена, мастер у автора | 2.5.1, перенесена 24.08.2026 |
| `promptmaker` | Перенесена, мастер у автора | 3.1, перенесена 24.08.2026. Добавлены разговорные триггеры в описание |

## Правило

Правишь перенесённую заготовку здесь — скажи автору, иначе изменение потеряется при следующем обновлении. Обновляешь её из оригинала — проверь, не затираешь ли местные правки: у `promptmaker` в описании дописаны триггеры под наш язык.

Заготовки, написанные здесь, живут только здесь — у них нет второго дома.
