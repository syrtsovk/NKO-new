# 1. Что поставить на компьютер

> Это делается один раз. Если рядом администратор — просто пройдите список вместе с ним.

Нужны три вещи. Все бесплатные, кроме подписки на ChatGPT.

## Помощник (Codex)

Открой программу **Терминал** (на Маке — поиск по слову «Терминал»; на Windows — «Командная строка» или PowerShell) и вставь туда строку целиком, потом нажми Enter:

```
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```

Пойдёт текст — это нормально, дождись, пока он остановится.

## Хранилище (Git)

Проверь, есть ли оно уже. Вставь в Терминал:

```
git --version
```

Если ответило номером версии — всё на месте, идём дальше. Если написало, что команда не найдена — скачай с [git-scm.com](https://git-scm.com/downloads) и установи, ничего не меняя в настройках.

## Доступ

Тебе понадобятся:

- **подписка ChatGPT** — под ней работает помощник;
- **приглашение в наше хранилище на GitHub** — придёт письмом, надо принять.

## Как понять, что всё получилось

Вставь в Терминал по очереди:

```
codex --version
git --version
```

Обе строки ответили номерами версий — готово, переходи к [следующей странице](2-первый-запуск.md).

Что-то не ответило — не разбирайся сам, напиши администратору. Это его работа, а не твоя.
