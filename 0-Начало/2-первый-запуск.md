# 2. Первый запуск

## Забрать общую папку себе

Один раз. Вставь в Терминал (адрес хранилища даст администратор):

```
git clone <адрес нашего хранилища>
```

На компьютере появится папка с документами. Запомни, где она лежит.

## Каждый раз, когда садишься работать

Вставь в Терминал две строки по очереди:

```
cd <путь к папке>
codex
```

Первая заводит тебя в нужную папку, вторая запускает помощника. Появится строка для ввода — можно писать словами, как в переписке.

## Первое, что стоит написать

```
Забери свежее из общего места и расскажи, что у нас горит по срокам
```

Помощник подтянет изменения коллег и покажет, где просрочки.

## Как с ним разговаривать

Обычными словами, как коллеге. Не надо команд и не надо точных названий файлов.

| Плохо | Хорошо |
|---|---|
| «открой файл 2026-08-24-kio.md» | «покажи последнее письмо от комитета по Ромашке» |
| «создай карточку в переписке» | «пришла претензия от комитета, вот текст — заведи» |
| «запусти скрипт сводки» | «что у нас горит» |

Если он что-то не понял — просто объясни другими словами. Ошибиться тут нельзя: он ничего не удаляет молча и всегда говорит, что сделал.

## Когда закончил

Напиши **«сохрани»**. Почему это важно — на [следующей странице](3-как-сохранять.md).
